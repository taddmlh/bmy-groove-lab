# Preview kit

BMY Drummer's built-in kit: **GeneralUser GS** by S. Christian Collins (https://www.schristiancollins.com/generaluser.php),
drum program 0 "Standard 1", rendered per BMY velocity label (gh 28, sf 46, n1 66, n2 82, a1 102, a2 116)
with FluidSynth 2.4.6 (`tools/fluid_render.cjs`, js-synthesizer) from BMY's bundled `GeneralUser-GS.sf2`. `tools/render_kit.py` is an older home-made renderer kept for reference.
