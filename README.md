# BMY Groove Lab

Personal tool: extract drums from a song on iPad (in-browser Demucs via onnxruntime-web/WebGPU) and turn them into BMY Drummer `.bmybank` patterns.

Stage 1: `index.html` is a speed test for Demucs on the iPad.

Credits: [demucs-web](https://github.com/timcsy/demucs-web) (MIT), Meta Demucs (MIT), ONNX Runtime Web (MIT).
